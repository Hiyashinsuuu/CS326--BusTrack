# Project Schedule

## Project: BusTrack – Real-Time Commuter Bus Information System

---

| Week | Goals | Deliverables |
|------|-------|-------------|
| Week 1 | Project kickoff, define scope, form team, assign roles | Team contract, initial repo setup |
| Week 2 | Write user stories, estimate story points, plan Sprint 1 | `backlog.md`, `sprint-1-plan.md`, `schedule.md`, `team-roles.md` |
| Week 3 | Identify risks, set up Git workflow, PR/issue templates, simulate change request | `risk-register.md`, `.github/` templates, updated backlog |
| Week 4 | Set up testing framework, write unit tests, log and fix 1 bug | `qa-plan.md`, `tests/`, `defect-log.md`, bug fix PR |
| Week 5 | Practice branching strategy, resolve merge conflict, create first release | `scm-notes.md`, `release-notes.md`, tag `v0.5-scm` |
| Week 6 | Set up CI pipeline (GitHub Actions), automate tests on every push | `.github/workflows/ci.yml`, CI passing screenshots |
| Week 7 | Deploy to live environment, write deployment and support docs | `deployment-plan.md`, `release-checklist.md`, `support-plan.md`, live URL |
| Week 8 | Identify tech debt, refactor 1 item, measure performance before/after | `tech-debt.md`, `performance.md`, refactor PR, tag `v0.8-maintenance` |
