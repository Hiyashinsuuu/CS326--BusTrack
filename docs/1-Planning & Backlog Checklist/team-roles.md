## Role Descriptions

### Scrum Master
Facilitates all Agile ceremonies (sprint planning, retrospective, daily standups). Removes blockers and keeps the team on track toward the sprint goal.

### Full-Stack Developer
Bridges frontend and backend work. Responsible for integrating APIs with the UI and ensuring end-to-end features are functional.

### Backend Developer
Designs and implements server-side logic, database models, and API contracts. Ensures data integrity and security.

### Frontend Developer / UI Designer
Translates requirements into pixel-perfect, accessible UI. Works closely with the backend developer to consume APIs correctly.

### QA Engineer
Validates that all features meet acceptance criteria before merging. Tracks bugs in the defect log and verifies fixes.

### DevOps / Deployment Lead
Sets up GitHub Actions CI, manages environment variables and secrets, deploys to production, and creates tagged releases.

## Communication
- **Daily Standups:** Every morning via group chat (What did I do? What will I do? Any blockers?)
- **Sprint Review:** End of each sprint — demo to the class
- **Tools:** GitHub (version control + PRs), Discord (team chat), Google Drive (shared documents)
