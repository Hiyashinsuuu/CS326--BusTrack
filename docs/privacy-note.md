# Privacy Note

## Project: BusTrack – Real-Time Commuter Bus Information System

---

## Data Collected

| Data | Why We Collect It | Who Can See It | Retention Period |
|------|------------------|---------------|-----------------|
| Bus GPS location | Show real-time bus position on map | All users | Last 24 hours only |
| User's favorite routes | Personalize the app experience | User only | Until account deleted |
| Bug/delay reports submitted by users | Improve data accuracy | Admin only | 30 days |
| App usage logs (anonymous) | Debug errors and improve performance | Dev team only | 7 days |

---

## What We Do NOT Collect
- We do not collect commuter GPS/location data
- We do not collect names, emails, or phone numbers unless voluntarily provided
- We do not sell any data to third parties
- We do not use tracking cookies or advertising trackers

---

## User Rights
- **Access:** Users can request a copy of their data at any time
- **Deletion:** Users can delete their account and all associated data
- **Correction:** Users can report incorrect information via the in-app report form
- **Opt-out:** Users can disable notifications and favorites without losing app access

---

## Data Security
- All data transmitted over HTTPS (TLS encrypted)
- API keys and secrets stored as environment variables — never in source code
- Database access restricted to backend service only — not exposed publicly

---

## Note on Demo Status
This is a student project submitted for CS326. Data collected is for demonstration purposes only and is not used in any commercial context. No real commuter data has been collected or stored.
